Multilingual Grammatical Error Annotation: Combining Language-Agnostic Framework with Language-Specific Flexibility

A two-tier grammatical error typology and a stanza-based reimplementation of errant for multilingual GEC annotation in English, German, Czech, Korean, and Chinese

BEA 2025

Mengyang Qiu1,2, Tran Minh Nguyen2, Zihao Huang2, Zelong Li3, Yang Gu2, Qingyu Gao2, Siliang Liu2, Jungyeul Park2,3

1Trent University, Canada 2Open Writing Evaluation, France 3University College London, UK 4The University of British Columbia, Canada

Paper (ACL Anthology) PDF arXiv Code

Abstract

Grammatical Error Correction (GEC) relies on accurate error annotation and evaluation, yet existing frameworks, such as errant, face limitations when extended to typologically diverse languages. In this paper, we introduce a standardized, modular framework for multilingual grammatical error annotation. Our approach combines a language-agnostic foundation with structured language-specific extensions, enabling both consistency and flexibility across languages. We reimplement errant using stanza to support broader multilingual coverage, and demonstrate the framework’s adaptability through applications to English, German, Czech, Korean, and Chinese, ranging from general-purpose annotation to more customized linguistic refinements. This work supports scalable and interpretable GEC annotation across languages and promotes more consistent evaluation in multilingual settings. The complete codebase and annotation tools can be accessed at https://github.com/open-writing-evaluation/jp_errant_bea.

Keywords Grammatical error correction (GEC) GEC evaluation errant / ERRANT Error typology M2 format stanza Universal Dependencies (UD) Multilingual GEC (MultiGEC) Korean & Chinese GEC Learner corpora

Method

The framework splits grammatical error annotation into two tiers so that annotations stay comparable across languages while still capturing language-specific phenomena:

  1. Language-agnostic core (MRU). Every edit is one of three operations—Missing (M), Replacement (R), or Unnecessary (U)—refined with Universal POS tags (e.g. M:NOUN, U:DET). Replacements use an explicit R:P1 → P2 pattern that records the POS of both the original and the corrected tokens.
  2. Structured language-specific extensions. Reusable templates for spelling (R:SPELL:PHONETIC, R:SPELL:SHAPE, R:SPELL:PHONOGRAPHIC), word order (R:WO) and word boundary (R:WB) errors (e.g. their → there, You can help me → Can you help me, ice cream → icecream). Phonetic similarity uses a pronunciation representation (a pronouncing dictionary for English, pinyin for Chinese, romanization otherwise); shape similarity compares rendered character images.
  3. UD-consistent preprocessing with stanza. errant is reimplemented on top of stanza (tokenization, POS tagging, dependency parsing; over 70 languages) instead of spaCy, so every language is analyzed under the same Universal Dependencies scheme. English-specific labels such as NOUN:POSS are kept by porting errant's classifier to UPOS and dependency relations.
  4. Graded customization. German and Czech use the core without language-specific modules; Korean adds word-boundary subtypes WB:M (missing space) and WB:U (extraneous space) and errors in functional morphemes (postpositions ADP, verbal endings PART, honorific suffixes HON); Chinese re-annotates the Chinese GSD treebank with LTP-style word boundaries and retrains stanza on it.

Annotations are written in the standard M2 format, so the output can be scored with the usual errant-style precision, recall and F0.5. Code: open-writing-evaluation/jp_errant_bea.

Main Results

  • Faithful English reimplementation. Scoring outputs of the T5 GEC system, the stanza-based reimplementation reproduces errant almost exactly: F0.5 0.5503 vs. 0.5501 (precision 0.6139 vs. 0.6123, recall 0.3890 vs. 0.3911).
  • Czech and German without language-specific modules. Operation counts stay close to the existing annotations: Czech (first 1,000 development sentences) 4,897 edits vs. 4,915 in Náplava et al. (2022) (Missing 695 vs. 693, Replacement 3,672 vs. 3,707, Unnecessary 530 vs. 515); German 6,270 vs. 6,385 in Boyd (2018) (1,310 / 4,348 / 612 vs. 1,341 / 4,406 / 638).
  • More explicit categories. Instead of language-specific tags such as DIACR (989 in Czech) or generic OTHER (834 in Czech, 670 in German), the most frequent labels become explicit POS transitions, e.g. NOUN → NOUN (760 Czech, 814 German) and VERB → VERB (465 Czech). A Czech word order edit (nemohla jsem → jsem nemohla) is labeled R:VERB AUX -> AUX VERB instead of a generic R:WO.
  • Korean and Chinese refinements. In Korean, 음식이 → 음식을 (food.NOM → food.ACC) is labeled R:NOUN -> NOUN:ADP as a case-marker correction. In Chinese, LTP-based segmentation keeps 为什么 (‘why’) as one token, avoiding the misleading GSD-based edit 什么 出现 了 (‘what has occurred’).
