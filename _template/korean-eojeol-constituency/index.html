Constituency Structure over Eojeol in Korean Treebanks

An eojeol-based constituency representation for Korean treebanks, with morphology in a separate annotation layer

arXiv 2025

Jungyeul Park1, Chulwoo Park2

1KAIST 2Anyang University

To appear in Korean Linguistics (John Benjamins).

Paper (arXiv) PDF

Abstract

The design of Korean constituency treebanks raises a central representational question concerning the choice of terminal units. Although Korean words are morphologically complex, treating morphemes as constituency terminals can obscure the distinction between word-internal morphology and phrase-level syntactic structure, and can create mismatches with eojeol-based dependency resources. This paper argues for an eojeol-based constituency representation, with morphological segmentation and fine-grained POS information encoded in a separate, non-constituent layer. A comparative analysis shows that, under explicit normalization assumptions, the Sejong, Penn Korean, and KAIST treebanks can be compared over a shared eojeol-based constituency backbone. Building on this result, we outline an eojeol-based annotation scheme that preserves interpretable constituency, supports cross-treebank comparison and constituency-dependency alignment, and provides a surface-form terminal layer for future end-to-end Korean constituency parsing.

Keywords Korean constituency treebank Eojeol (어절) Korean syntax Constituency parsing Sejong treebank Penn Korean treebank KAIST treebank Treebank normalization UPOS / Universal Dependencies Constituency–dependency alignment

From Morpheme Terminals to Eojeol Terminals

An eojeol is the orthographic spacing unit of Korean: a lexical stem plus one or more functional morphemes such as case markers or verbal endings. Existing treebanks place morphology at or inside the terminal layer in different ways. The original Sejong tree below keeps one eojeol per leaf but packs the morpheme/POS sequence into the terminal string (e.g. 프랑스/NNP+의/JKG) and enforces strictly binary branching; the Penn Korean treebank adds null elements such as *pro* and canonicalizes functional morphemes; the KAIST treebank splits functional morphemes into separate terminals.

The proposed annotation scheme:

  1. Eojeol terminals. Phrase structure is built only over surface eojeol (and punctuation tokens); morphemes are never constituency terminals.
  2. UPOS preterminals. Each eojeol is dominated by one Universal POS label reflecting the syntactic role of the whole eojeol, which keeps the token and category interface compatible with eojeol-based (UD-style) dependency treebanks.
  3. A parallel morphological layer. Morphological segmentation with fine-grained Sejong XPOS tags is stored as an aligned, non-constituent annotation that introduces no nodes into the tree.
  4. A six-column CoNLL-like format. ID, surface form, morphological segmentation (XPOS), UPOS, and left/right bracketing columns; the tree is recoverable from columns 2, 4, 5, and 6 alone, so constituency parsing does not need gold morpheme segmentation.
  5. Normalization of existing treebanks. Debinarize Sejong, remove null elements from Penn Korean, and collapse morpheme-level terminals in KAIST, so that all three share the same eojeol yield.

Main Findings

  • A shared backbone. Under explicit normalization assumptions, the Sejong, Penn Korean, and KAIST treebanks can be compared over a common eojeol-based constituency yield, which can be aligned directly with eojeol-based dependency tokens without reconstructing morpheme boundaries.
  • Smaller yields. In a small structural validation on five sample sentences per treebank, normalization reduces the average number of terminals from 18.20 to 10.20 (Sejong), 30.20 to 15.20 (Penn Korean), and 18.40 to 10.20 (KAIST).
  • Less annotation-induced structure. Average nonterminals drop from 34.40 to 18.80 (Sejong, from debinarization), 50.80 to 31.60 (Penn Korean, from null-element removal), and 32.80 to 23.20 (KAIST, from collapsing morpheme projections); average depth falls most for Sejong (5.47 → 4.00).
  • Phrase structure is preserved. Average branching changes only modestly (e.g. 1.50 → 1.49 for Sejong), so normalization removes resource-specific material rather than the phrase-structural organization; the authors stress this is not a ranking of treebanks or a parsing evaluation.
